## 制作メモ
- 公式写真（by お店）は無加工で使用。一般ユーザーの投稿写真は Seedream 4.5（画像生成）で構図・料理・器を保ったまま少しだけデフォルメしたイラストに描き直して使用（Seedanceは不使用）。
- 横長素材は見切れないように全体をカード表示し、背景には同じ写真をぼかして敷いている。
- テロップは Noto Sans/Serif CJK。発話タイミングに合わせてマスク・ポップで表示。文字はShorts/ReelsのUIと重ならない y≒200〜1560 の範囲に配置。
- ナレーション: Kokoro TTS（ONNX, 音声 jf_alpha）。日本語音声認識で全文が正しく聞き取れることを確認済み。
- BGM・効果音は numpy で自作した合成音（権利フリー）。差し替える場合は `src/build_audio.py` の BGM 部分を置き換える。
- ※198円などの価格・内容は掲載時点の情報。公開前に店舗に確認すること。
